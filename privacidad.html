Política de privacidad

Aplicación: Respaldo NAS Felipe.

Responsable: Felipe, titular y administrador de esta integración de uso personal.

Datos a los que se accede y finalidad

La integración utiliza la API de Google Drive, previa autorización del titular, para consultar metadatos —por ejemplo, nombres, identificadores, tamaños y fechas de modificación— y descargar el contenido necesario para mantener una copia local de la carpeta configurada.

Se utiliza el permiso de solo lectura drive.readonly. Aunque este permiso puede permitir el acceso a los archivos de Drive accesibles por la cuenta, la tarea de copia se configura para una carpeta seleccionada. La integración no modifica ni elimina archivos del Drive de origen.

Almacenamiento y acceso

Los archivos descargados se almacenan en el NAS administrado por el titular. El acceso a las copias depende de los permisos de las carpetas compartidas y de la configuración de la red del NAS. Las credenciales de rclone se guardan separadas de las carpetas públicas, en una ubicación de acceso restringido.

Los registros de funcionamiento pueden contener nombres de archivos, rutas, fechas y mensajes de error, y se utilizan para supervisar la copia y resolver incidencias.

Uso y comunicación de los datos

Los datos de Google Drive se utilizan únicamente para realizar y administrar la copia personal. Esta integración no los vende, no los utiliza para publicidad y no los publica en este sitio web ni los envía a GitHub Pages.

Conservación y eliminación

Las copias se conservan en el NAS hasta que el titular las elimine manualmente. Borrar un archivo de Google Drive no elimina automáticamente su copia local. Actualizar un archivo puede reemplazar la versión local anterior.

El titular puede detener la tarea programada y revocar el acceso de la aplicación desde su cuenta de Google. Revocar el acceso detiene las futuras consultas autorizadas, pero no elimina por sí solo los archivos ya descargados; estos deben eliminarse directamente del NAS.

Credenciales

El inicio de sesión y la autorización se realizan con Google. Este sitio informativo no solicita ni almacena contraseñas, tokens OAuth ni archivos de configuración de rclone.

Alojamiento de esta página

Esta página está prevista para alojarse en GitHub Pages. No incorpora formularios ni herramientas propias de analítica. GitHub puede registrar la dirección IP de los visitantes por motivos de seguridad; esto es independiente del contenido del respaldo de Drive.

Información del proveedor: recogida de datos en GitHub Pages.

Contacto y cambios

Para consultas, utiliza el correo de asistencia indicado en la configuración de consentimiento OAuth de «Respaldo NAS Felipe» en Google. Esta política debe actualizarse si cambian el funcionamiento, los permisos o el tratamiento de datos de la integración.

Integración personal administrada por Felipe. No es un servicio oficial de Google, Western Digital ni del proyecto rclone.
